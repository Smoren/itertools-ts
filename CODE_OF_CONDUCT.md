# Code of Conduct

## Our Goal
The main goal of this project is to build high-quality software. We welcome contributions from anyone, regardless of background, as long as the contribution improves the project and meets our technical standards.

## Scope
This Code of Conduct applies to all project spaces: the repository (issues, pull requests, discussions, code comments) and any community channels (e.g., Telegram chat, forums) where project activity takes place. It also applies to official project representations, such as posts on social media by project maintainers.

## Technical Meritocracy
Participation in this project is based on technical merit, skills, and the quality of contributions. Ideas and code are judged by their usefulness, efficiency, and correctness, not by who submits them. A person's background, identity, or popularity never substitutes for technical quality — and never makes disrespectful behavior acceptable.

## Expected Behavior
* **Professionalism:** Keep all discussions focused on tech, code, architecture, and documentation.
* **Respect:** Treat other maintainers and contributors with professional courtesy. Critiques must be constructive and directed at the code, never at the person.
* **Honesty:** Provide honest, clear, and direct feedback on pull requests and issues.

## Unacceptable Behavior
* Personal attacks, insults, or aggressive behavior toward other members.
* Derailing technical discussions into personal grievances or off-topic political/social arguments.
* Spam, flooding, and public harassment.

## Enforcement
The project maintainers are responsible for enforcing these standards. If you encounter unprofessional behavior, please report it to [ofigate@gmail.com](mailto:ofigate@gmail.com).

Reports are handled with confidentiality: the identity of the reporter is shared only with the maintainers directly involved in resolving the case. Every report will be reviewed and a decision will be made in a timely manner. The reporter will be informed of the outcome to the extent appropriate.

Maintainers have the right to edit, reject, or delete comments, issues, or pull requests that violate this code, and to ban users temporarily or permanently for toxic behavior. Appeals of enforcement decisions can be submitted to the same address and will be reviewed by the maintainers.
